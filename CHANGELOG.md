# Changelog

Initial Django/SQLite CRM MVP: scoped session authentication, dashboard graphs and metrics, customer profiles and stage history, itemised orders, payments/balances, follow-ups, product catalogue, monthly team targets, operations activity, filtered CSV/XLSX exports, printable orders, migrations, optional fictional demo data and 36 integration tests. Includes setup, schema/ERD, route, testing and operations documentation.
